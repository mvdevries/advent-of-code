## 🛠️ Over Advent of Code

[Advent of Code](https://adventofcode.com/) is een jaarlijkse programmeer-adventskalender gemaakt door Eric Wastl.  
Elke dag van 1 t/m 25 december verschijnt een nieuwe puzzel, met soms een onverwachte kersttwist.  
Het is een geweldige manier om:

- Je programmeervaardigheden te verbeteren  
- Nieuwe technieken of talen uit te proberen  
- Logisch te puzzelen  
- Samen te leren, delen en vergelijken
